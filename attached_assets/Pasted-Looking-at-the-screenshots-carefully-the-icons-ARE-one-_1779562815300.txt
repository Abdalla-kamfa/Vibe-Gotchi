ICON CONSISTENCY RULES
Apply these rules to EVERY icon in the app:
Size scale:

Navigation/small UI: 14px
Stat labels: 14-16px
Buttons: 16-18px
Feature cards: 24px
Empty states: 48px
Hero/decorative: 28-32px

Stroke width:

All icons: strokeWidth={1.5} for elegant feel
Bold/emphasis icons: strokeWidth={2}
Very small icons: strokeWidth={2} (needs more weight)

Color system:

Green accent: #00ff88 — primary actions, health
Red accent: #ff4444 — battle, danger, errors
Yellow accent: #ffdd00 — energy, stars
Orange accent: #ff8800 — streak, warning
Gold accent: #ffaa00 — level, trophies, legend
Purple accent: #8844ff — AI, vibe, magic
Muted: #666666 — secondary, inactive
Very muted: #444444 — disabled, placeholder

Hover effects on all interactive icons:
css.interactive-icon {
  transition: all 150ms ease;
}
.interactive-icon:hover {
  transform: scale(1.15);
  filter: brightness(1.3);
}
Focus rings for accessibility:
css.interactive-icon:focus-visible {
  outline: 2px solid #00ff88;
  outline-offset: 4px;
  border-radius: 4px;
}
