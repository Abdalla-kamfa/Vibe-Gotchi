The pet evolves, gains stats, changes mood, and unlocks outfits based on real GitHub data. This must feel like a polished, launch-ready product — not a hackathon prototype.

State: React useState/useEffect + localStorage for session leaderboard
Deployment: Must run cleanly on Replit with a single npm run dev command

GITHUB DATA FETCHING
Use these public GitHub API endpoints (no auth token needed for basic use, but add GITHUB_TOKEN env var support for higher rate limits):
GET https://api.github.com/users/{username}
GET https://api.github.com/users/{username}/events/public?per_page=100
GET https://api.github.com/users/{username}/repos?sort=updated&per_page=30
From this data, calculate:

commitCount30Days — count PushEvents in last 30 days
lastCommitDate — most recent PushEvent date
currentStreak — consecutive days with at least one PushEvent
topLanguage — most common language across repos
totalStars — sum of stargazers_count across all repos
recentCommitMessages — last 5 commit message strings from PushEvents
totalRepos — public_repos from user object

Handle errors gracefully:

Username not found → friendly error state with sad egg and message: "This username doesn't exist... or they deleted everything out of shame."
Rate limited → show: "GitHub is being shy. Try again in a moment."
Empty activity → treat as 0 commits (show dead/sad pet state)


AI INTEGRATION (OpenAI)
Create a Next.js API route: POST /api/analyze-vibe
Request body:
json{
  "commitMessages": ["fix bug", "add feature", "wip", "..."],
  "topLanguage": "Python",
  "commitCount": 23,
  "daysSinceLastCommit": 1
}
System prompt to send to GPT-4o-mini:
You are a witty, slightly sarcastic AI that analyzes a developer's GitHub commit history and gives their virtual pet a personality. Based on the commit messages, language, and activity provided, return ONLY a JSON object with these exact fields:
{
  "vibeOneLiner": "string (max 60 chars, punchy, funny, true to their coding style)",
  "petPersonality": "string (one word: Chaotic | Disciplined | Sleepy | Feral | Legendary | Ghost)",
  "moodBoost": "positive | neutral | negative"
}
No markdown. No explanation. JSON only.
Use the vibeOneLiner as the Vibe stat in the stats panel.
Use petPersonality as a subtitle under the pet name.
Use moodBoost to slightly adjust the mood display.
If OpenAI call fails, fall back to rule-based vibe strings — never show an error to the user.
